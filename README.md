# Folderito

Музыкальный плеер для Android: библиотека строится **по папкам** устройства,
можно слушать выбранные папки и отдельно выбранные треки. Написан на Kotlin +
Jetpack Compose.

## Возможности (v0.1)

- **Библиотека по папкам** — раскрывающееся дерево папок со статистикой
  (путь, количество папок/треков, общая длительность).
- **Выбор треков и папок** — чекбоксы (у папок три состояния: пусто / частично / всё),
  панель «Выбрано: N треков · ≈ X мин» с кнопкой воспроизведения.
- **Поиск** по названию, исполнителю и альбому с подсветкой совпадений.
- **Плеер** — обложка с вращающейся виниловой пластинкой, чипы «альбом / папка»,
  перемотка, shuffle / prev / play / next / repeat (выкл → все → один).
- **Эквалайзер** — системный (android.media.audiofx): 8 пресетов + «Свои»,
  реальные полосы устройства, усиление басов, объёмный звук.
- **Цветовые схемы** — Стандартная, Своя, Туман, Олива: пять базовых цветов
  разворачиваются в полную таблицу токенов оформления; вдобавок тёмная/светлая
  тема и следование системной.
- **Язык** — русский / английский (или системный).
- Фоновое воспроизведение с медиа-уведомлением (Media3 / ExoPlayer).

## Как собрать

1. Установите **Android Studio** (последняя версия): https://developer.android.com/studio
2. Откройте папку проекта (File → Open). Studio сама скачает SDK и Gradle —
   согласитесь с предложениями.
3. Включите на телефоне режим разработчика и **отладку по USB**
   (Настройки → О телефоне → 7 раз тапнуть «Номер сборки»; затем
   Настройки → Для разработчиков → Отладка по USB).
4. Подключите телефон, выберите его в списке устройств и нажмите **Run ▶**.

Сборка APK без Android Studio (нужен JDK 17 в PATH):
`gradlew.bat assembleDebug` → `app\build\outputs\apk\debug\app-debug.apk`.

## Технологии

| Слой | Решение |
|---|---|
| UI | Jetpack Compose, Material 3, шрифт Manrope (веса 500–800) |
| Воспроизведение | Media3 ExoPlayer + MediaSessionService |
| Данные | MediaStore (разрешение только на аудио — дружелюбно к Google Play) |
| Эквалайзер | android.media.audiofx: Equalizer, BassBoost, Virtualizer |
| Настройки | DataStore Preferences (тема, скин, язык, пресет, полосы, бас/объём) |

## Дорожная карта

- Выбор корневых папок библиотеки (скрывать служебные папки)
- Обложки из встроенных в файлы тегов (fallback — градиент)
- Виджеты, sleep-timer, скорость воспроизведения

## Структура

```
app/src/main/java/com/foldersound/
├── FsApp.kt                  — приложение, синглтоны (репозиторий, подключение)
├── MainActivity.kt           — вход, разрешения, тема
├── data/                     — модели, MediaStore-репозиторий, DataStore
├── playback/                 — сервис, MediaController, эквалайзер
└── ui/
    ├── theme/                — цветовые токены, скины, типографика
    ├── i18n/                 — строки RU/EN, множественные формы
    ├── common/               — обложки, ползунки, чекбоксы, анимации
    ├── icons/                — векторные иконки
    ├── library/              — главный экран: дерево папок, шторка
    ├── player/               — экран «Сейчас играет»
    ├── songs/                — экран «Список песен»
    ├── eq/                   — экран «Эквалайзер»
    └── settings/             — цветовые схемы, тема, язык
```
