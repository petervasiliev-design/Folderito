# Folderito

Музыкальный плеер для Android: библиотека строится **по папкам** устройства,
можно слушать выбранные папки и отдельно выбранные треки. Написан на Kotlin +
Jetpack Compose.

## Возможности

### Библиотека
- **Библиотека по папкам** — раскрывающееся дерево папок со статистикой
  (путь, количество папок/треков, общая длительность).
- **Выбор треков и папок** — чекбоксы (у папок три состояния: пусто / частично / всё),
  панель «Выбрано: N треков · ≈ X мин» с транспортом и переходом в плеер.
- **Избранное и скрытые папки** — удержание на плитке папки открывает меню:
  добавить в избранное (раздел «Избранное» после плейлистов, у плитки звезда;
  папка остаётся и в дереве) или спрятать (папка исчезает из дерева, поиска
  и списка песен). Списки управляются в настройках.
- **Поиск** по названию, исполнителю и альбому: результаты группами —
  «Папки» (раскрываются на месте) и «Песни».
- **Быстрое проигрывание** — двойной тап по треку при пустом выборе играет
  всю его папку; внизу — панель с именем папки и кнопками управления.

### Плейлисты
- **Плейлисты .m3u/.m3u8** — читаются из общей памяти и показываются в дереве
  (раскрыть, удержание — играть, галочка — выделить).
- **Сохранение плейлиста** — кнопка в «Списке песен» записывает показанный
  список (выделение или играющую папку) файлом .m3u.

### Плеер
- **Плеер** — обложка-конверт, из которого справа выглядывает виниловая
  пластинка (фотография, крутится при воспроизведении, оборот за 5,4 с),
  чипы «альбом / папка», перемотка,
  shuffle / prev / play / next / repeat (выкл → все → один).
- **Настройки аудиокниг** — скорость 0,5–2×, вырезание пауз, «Чёткость речи»
  (голосовой пресет, перекрывает эквалайзер).
- **Таймер сна** с пресетами и отсчётом в шторке.
- **Эквалайзер** — системный (android.media.audiofx): 8 пресетов + «Свои»,
  реальные полосы устройства, усиление басов, объёмный звук.
- **Подсказки** — удержание на кнопках шапки открывает окно с описанием.

### Оформление и данные
- **Цветовые схемы** — Стандартная, Янтарь, Туман, Олива, Сталь (со своей
  тёмной парой): пять базовых цветов разворачиваются в полную таблицу токенов
  оформления; вдобавок тёмная/светлая тема и следование системной.
- **Язык** — русский / английский / немецкий (или системный).
- Фоновое воспроизведение с медиа-уведомлением (Media3 / ExoPlayer);
  возобновление после перезапуска и по медиа-кнопке (Tasker/MacroDroid,
  магнитола).

## Как собрать

1. Установите **Android Studio** (последняя версия): https://developer.android.com/studio
2. Откройте папку проекта (File → Open). Studio сама скачает SDK и Gradle —
   согласитесь с предложениями.
3. Включите на телефоне режим разработчика и **отладку по USB**
   (Настройки → О телефоне → 7 раз тапнуть «Номер сборки»; затем
   Настройки → Для разработчиков → Отладка по USB).
4. Подключите телефон, выберите его в списке устройств и нажмите **Run ▶**.

Сборка APK без Android Studio (нужен JDK 17 в PATH):
`gradlew.bat assembleDebug` → `app\build\outputs\apk\debug\app-debug.apk`.

Релизная сборка (`gradlew.bat assembleRelease` →
`app\build\outputs\apk\release\app-release.apk`) подписывается ключом из
`local.properties` (переменные `release.storeFile`, `release.storePassword`,
`release.keyAlias`, `release.keyPassword`); сам файл ключа в git не входит —
храните его и пароли в надёжном месте, они нужны для всех обновлений.

## Технологии

| Слой | Решение |
|---|---|
| UI | Jetpack Compose, Material 3, шрифт Manrope (веса 500–800) |
| Воспроизведение | Media3 ExoPlayer + MediaSessionService |
| Данные | MediaStore: аудио (разрешение только на аудио — дружелюбно к Google Play), .m3u через MediaStore.Files / MediaStore.Audio.Playlists |
| Эквалайзер | android.media.audiofx: Equalizer, BassBoost, Virtualizer, DynamicsProcessing (скорость, вырезание пауз) |
| Настройки и состояние | DataStore Preferences: тема, скин, язык, эквалайзер, скорость, очередь (в т.ч. база перемешивания), выделение, раскрытые папки, избранное, скрытые папки, сохранённая позиция |

## Дорожная карта

- Выбор корневых папок библиотеки (часть задачи уже решена скрытием папок)
- Обложки из встроенных в файлы тегов (fallback — градиент)
- Виджеты на рабочий стол
- Экспорт плейлистов с относительными путями («переносимый» файл)

## Структура

```
app/src/main/java/com/foldersound/
├── FsApp.kt                  — приложение, синглтоны (репозиторий, подключение)
├── MainActivity.kt           — вход, разрешения, тема
├── data/                     — модели, MediaStore-репозиторий, DataStore
├── playback/                 — сервис, MediaController, эквалайзер
└── ui/
    ├── theme/                — цветовые токены, скины, типографика
    ├── i18n/                 — строки RU/EN/DE, множественные формы
    ├── common/               — обложки, ползунки, чекбоксы, диалоги, жесты
    ├── icons/                — векторные иконки
    ├── library/              — главный экран: дерево, избранное/скрытые, панели
    ├── player/               — экран «Сейчас играет»
    ├── songs/                — экран «Список песен» (+ сохранение плейлистов)
    ├── eq/                   — экран «Эквалайзер»
    ├── sleep/                — экран «Таймер сна»
    └── settings/             — цветовые схемы, тема, язык, перемотка, списки папок
```
