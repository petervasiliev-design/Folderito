# Словарь Folderito

Краткие имена, которыми называем элементы интерфейса. Одно-два слова — и понятно, о чём речь.

| Термин | Что это | В коде |
|---|---|---|
| **Основной экран** (дерево, папки) | Первый экран выбора папок: заголовок «Folderito», дерево папок с чекбоксами, поиск | `LibraryScreen` |
| **Панель плеера** | Нижняя панель на основном экране: обложка, название, play/next, полоска прогресса | `MiniPlayer` |
| **Плеер** | Экран плеера: большая обложка с пластинкой, перемотка, управление | `PlayerScreen` |
| **Эквалайзер** | Экран эквалайзера: пресеты, полосы, бас/объём | `EqualizerScreen` |
| **Список песен** | Экран текущей очереди воспроизведения: что запущено — то в списке; удержание переключает на песню. Вход — стрелкой/свайпом из плеера | `SongsScreen` |
| **Шторка** (меню) | Боковая панель по кнопке «три полоски»: эквалайзер, список песен, тема, язык | `AppDrawer` |
| **Панель выбора** | Нижняя панеля при выбранных треках: «Выбрано: N · ≈X мин», сброс, играть | `SelectionBar` |
| **Черта** (гнездо) | Вертикальная линия слева от вложенных строк раскрытой папки | `nestLine` |
| **Подпись папки** | Вертикальная надпись имени папки на черте | `NestTag` |
| **Плитка папки** | Коричневая строка папки в дереве | `FolderRowView` |
| **Строка трека** | Строка песни: чекбокс, обложка, название, длительность | `TrackRowView` |
| **Кнопка «Свернуть все»** | Кнопка в шапке основного экрана (стрелки внутрь) | — |
